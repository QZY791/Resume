1. 三分钟上手

整个网站就在 交付包 这个文件夹里，双击一个文件就能用，不需要安装、不需要联网。

启动

  1. 打开 交付包 文件夹，双击 启动.bat。
  2. 会弹出一个黑色命令行窗口，上面印着访问地址，例如 http://127.0.0.1:8888/。
  3. 浏览器通常会自动打开。如果没自动开，把这个地址复制到浏览器地址栏回车即可。

关闭：直接关掉那个黑色窗口，或在窗口里按 Ctrl + C。关掉之后浏览器里就打不开了，这是正常的。

为什么必须用这个 启动.bat，不能直接双击网页文件？

这是个单页应用，直接用 file:// 打开网页文件会出两个问题：刷新页面就报 404；部分浏览器还会禁用本地数据库，导致数据存不进去。启动.bat 只是在你自己电脑上起一个仅本机可见的小服务（127.0.0.1，外网访问不到），把这些问题绕开。

关于 Node.js

启动.bat 需要一个叫 Node.js 的运行环境。它启动时会按顺序自动去找：

  1. 系统 PATH 里的 node.exe；
  2. WorkBuddy 内置的 Node（%USERPROFILE%\.workbuddy\binaries\node\versions\ 下取最新版本）；
  3. 常见的安装位置（C:\Program Files\nodejs\ 等）。

三处都没找到时，窗口会提示你去 https://nodejs.org/ 下载 LTS 版本，装完再双击一次即可。本机已经装好了，正常情况你不用管这一步。

端口被占用怎么办？

默认端口是 8888。如果它被别的程序占了、或者被 Windows 保留（装了 Hyper-V / WSL 的机器上常见），服务器会自己往后顺延，并把实际用的地址印在窗口里。以窗口里印出来的地址为准。必要时把端口号往后调几位也行，见第 10 节的说明。

3. 四个核心流程

流程一 · 先把个人资料填一次

进「01 个人资料库」，把姓名、手机、邮箱、所在地、教育经历、技能、语言、证书、链接填好保存。这部分是可复用的底座，之后每份简历都从这里取。

流程二 · 往里攒经历

进「02 经历管理」，点新建，选类型填内容。两条实用建议：

  • 「原始笔记」尽量写全。哪怕是大白话、时间线混乱也没关系。这一栏是后续 AI 整理的唯一输入，写得多，整理出来的东西才有料。
  • 背景 / 目标 / 行动 / 成果（STAR）四栏可以手动填，也可以让 AI 填。填完记得在「来源附件」处把相关素材挂上，之后翻经历时能一眼看到当时的截图或笔记。

每条经历有三种状态，通过列表右侧的按钮流转：

状态含义
草稿还在写，或者还没想清楚要不要用
已确认内容核实过了。组装简历时从这里挑
已归档暂时不用了，但不想删

任意状态都能退回草稿。归档不等于删除，记录会一直在。

流程三 · 上传素材

进「03 素材与附件」，拖拽或点选上传。限额是：

类型格式单个大小
图片JPG / PNG / GIF / WebP≤ 2 MB
文档PDF / TXT / MD≤ 5 MB

上传后可以在素材详情里写摘要、填来源日期、关联到一条或多条经历。关联是双向的 —— 在经历那边也能看到挂上的素材。素材主要用于留档和辅助回忆，不会直接出现在导出的简历里。

流程四 · 组装并导出简历

进「04 生成简历」，点新建，按 6 个区块往下填：

1 基本信息→ 2 勾选经历→ 3 栏目与顺序→ 4 模板→ 5 内容微调→ 6 AI 生成文案（可选）
  • 基本信息：简历语言（中文 / 英文）、目标岗位，还可以粘贴岗位 JD 供 AI 参照。
  • 勾选经历：从「已确认」的经历里挑。
  • 栏目与顺序：调整简历上各栏的先后，也能关掉不想显示的栏目（至少要留一个）。
  • 模板：目前一种默认版式。
  • 内容微调：逐条改自我介绍和经历正文的措辞。想恢复成从经历库自动拼出来的版本，点重建即可。
  • AI 生成文案：可选增强。没配 AI 也能正常保存和导出。

保存后草稿落到本地库。回到「04 生成简历」列表，点进某份草稿就是编辑器：左边改内容，右边实时预览 A4 效果，顶部工具栏显示「共 N 页」。

4. AI 整理怎么配

这一块是可选的。不配也不影响任何其他功能，只是少了「把大白话笔记自动整理成 STAR」和「按岗位生成文案」这两个帮手。

进「AI 整理设置」，填三项必填：

字段说明
接口地址 baseUrl大模型服务的地址。用上面的「供应商预设」可以一键填好前两项
模型名 model如 deepseek-chat / gpt-4o-mini / qwen-plus
API Key去对应服务商后台申领，粘贴进去
温度 temperature整理任务建议 0.2 ~ 0.4，越低越稳定、越不容易自己发挥

内置了三个预设，选中会自动填好地址和模型：

  • DeepSeek —— https://api.deepseek.com，模型 deepseek-chat
  • OpenAI —— https://api.openai.com/v1，模型 gpt-4o-mini
  • 通义千问（兼容模式） —— 阿里云 DashScope 的 OpenAI 兼容端点，模型 qwen-plus

填完点「测试连通性」，通了再点保存。之后在经历表单里就能看到「AI 整理原始笔记」按钮：点开 → 带着原文的弹窗打开 → 点开始整理 → 核对结果 → 「应用结果」回填到 STAR 四栏。

两个必须知道的点：

  • API Key 是明文存在浏览器里的（localStorage），只在本机。它不会进入备份文件，换电脑导入备份后需要重新填一次。别在公用电脑上配置。
  • 部分服务商不允许浏览器直连（跨域限制），表现为测试连通性时报网络错误。这种情况换一家支持浏览器直连的服务商，或改用自己的中转地址。

5. 导出 PDF

在简历编辑器右上角点「导出 PDF」：

  1. 先弹一个说明框，点「打开打印对话框」。（点它之前系统会自动保存一次，保证导出和库里内容一致。）
  2. 浏览器打开系统的打印对话框。关键三项：
    • 目标 / 打印机 → 选「另存为 PDF」
    • 边距 → 选「无」（页边距已经做在内容里了，再选默认边距会串版）
    • 缩放 → 保持 100%
  3. 点保存，选个目录存下来。

导出的是矢量 PDF：文字可以选中、可以复制、能被招聘系统解析，不是一张图片。页面里的浅粉底色已强制保留，不需要去勾「背景图形」（勾了也无妨）。

怎么判断导对了？

  • 打开 PDF，用鼠标拖选一段文字 —— 能选中的就是矢量输出。
  • 对照编辑器顶部的「共 N 页」：PDF 页数应该和它一致，且最后几行没被裁掉。

如果 PDF 里出现半页空白或内容被截断，通常是打印对话框里「边距」被改成了默认值（不是「无」）。重新导出并确认边距选「无」即可。

6. 管理与设置

回收站

删除经历、素材、简历草稿时不会真的删掉，而是先进回收站。里面有「恢复」和「彻底删除」两个动作，也支持一键清空。要真正的空间回收和不可恢复的删除，得走「彻底删除」。

数据完整性检查

进页面会自动扫一遍，检查两类问题：引用了不存在的记录（孤立引用）、两边关联关系对不上（双向关联不对称）。每条问题都能单独点「修复」，修复只调整引用数组，不会删掉你的经历、素材或简历草稿本身。报告可以导出。

数据与隐私安全

  • 存储统计：看各类数据占用多少空间，回收站里的条目也占空间，建议定期清空。
  • 导出备份：把全部数据导出成一个 JSON 文件。
  • 导入恢复：从 JSON 备份恢复，导入前会先给你看一眼要导入什么。
  • 清空所有数据：需要手动输入「删除」两字才能确认，做完不可恢复。

7. 备份与恢复（强烈建议养成习惯）

数据只存在浏览器本地，没有任何服务器帮你存。这意味着：清一次浏览数据、换一次浏览器、重装一次系统，数据就没了。所以：

  • 每周（或每写完几条重要经历）去「数据与隐私安全」点一次「导出备份」，文件名形如 resume-material-backup-20260930-173000.json，存到网盘或别的盘。
  • 换电脑时：老机器导出备份 → 新机器装好交付包 → 进「数据与隐私安全」用「导入备份」读进去。

导入是「合并导入」，不是覆盖。同一条记录（id 相同）会被备份里的版本覆盖，备份里没有的记录会原样保留。所以导入一份旧备份不会把新加的内容清掉，但被覆盖的那几条会回到备份时的样子。

8. 数据到底存在哪

内容存在哪会不会进备份
个人资料、经历、素材、简历草稿本机浏览器 IndexedDB，库名 resume-material-db会
素材的图片和文件本体同上（以 Base64 形式存在记录里）会
AI 的 API Key 与配置本机浏览器 localStorage不会

「库名 resume-material-db」的意义：它和其他网站的存储是隔离的，别的网站读不到，这个网站也只读自己的。

会让数据「看起来消失」的操作：

  • 换一个浏览器打开（Chrome 和 Edge 的本地库互不相通）
  • 用无痕 / InPrivate 窗口
  • 清理「Cookie 及其他网站数据」并勾选了网站存储
  • 卸载重装浏览器

这些情况下数据并没有被上传到任何地方（本来也没有服务器），只是你换了一个空的本地库。固定用一个浏览器的普通窗口使用，并定期导出备份，就不会踩到。

9. 常见问题

现象原因与处理
双击 启动.bat 窗口一闪就没了 多半是没找到 Node.js。右键用记事本打开 启动.bat 看不到有用信息；正确做法是在命令行里跑一次看报错，或直接按提示装一遍 Node.js LTS。
提示 Node.js was not found 按窗口里给的网址装 Node.js（选 LTS 版），装完重新双击 启动.bat。
浏览器打开了但页面空白 / 打不开 先看黑窗口里印的实际地址是不是和你访问的一致（端口可能顺延过）。仍不行就关掉窗口重开一次。
页面能开，但数据都是空的 你换了浏览器、用了无痕窗口，或清了浏览数据。回到常用浏览器的普通窗口，或用备份导入恢复。
提示端口被占用 不用管，服务器会自动换端口，实际地址以窗口里印的为准。
AI 测试连通性报 401 / 404 / 超时 / 网络错误 401 是 Key 不对；404 是地址或模型名不对；超时和网络错误多半是服务商不允许浏览器直连（跨域）。逐项核对后再试。
导出的 PDF 和预览不一样 / 后半页空白 打印对话框里「边距」要选「无」、「缩放」要 100%。这两项改对了通常就一致了。
素材上传失败 检查格式和大小：图片限 JPG / PNG / GIF / WebP 且 ≤ 2MB，文档限 PDF / TXT / MD 且 ≤ 5MB。

10. 想改代码 / 更新版本

源码工程在 D:\个人简历素材库\A（交付包 只是它的构建产物）。

命令作用
npm install装依赖（首次或依赖变动后）
npm run dev起开发服务器，改代码即时热更新，默认 localhost:5173
npm run build类型检查 + 打包，产物在 dist/

改完代码后更新交付包的步骤：跑 npm run build，把 dist\ 里的全部内容复制覆盖到 交付包\www\，再双击 启动.bat 即可。交付包里的 server.mjs 与 启动.bat 不需要重新生成。

想改端口：编辑 交付包\server.mjs，把 const START_PORT = 8888 改成你要的数字。注意避开 Windows 给 Hyper-V / WSL 保留的端口段，用管理员命令行执行 netsh interface ipv4 show excludedportrange protocol=tcp 可以查到保留范围。

11. 已知限制与后续计划

当前版本的限制

  • 单机单浏览器。没有账号体系，数据不跨设备。换设备要靠导出 / 导入备份。
  • 简历模板只有一种。版式后续会扩展。
  • 服务商直连限制。AI 整理能不能用，取决于该服务商是否允许浏览器直接请求。
  • 回收站清空后不可恢复。「彻底删除」和「清空回收站」都是真删。

后续计划

  • 跨设备同步与服务端存储。数据访问层已经预留了替换点（StoragePort / AssetBlobStore），届时换一个适配器实现即可，业务模块不用改。
  • 更多简历版式，以及对外导出 JSON Resume 标准格式，方便投给支持该格式的招聘系统。
